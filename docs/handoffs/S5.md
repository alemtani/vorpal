# S5 handoff

Payload assembly and the model call. SPEC.md section 4.

S4 was not on `main`. `BoardRow`, `DraftState`, and `Replacement` come from
`vorpal.contracts`. Callers pass already-valued rows.

## What other sessions call

```python
from vorpal.payload import BOARD_CAPPED, build_payload, cap_board
from vorpal.model import (
    MODEL_ID,  # "claude-opus-5" from the claude-api skill
    AnthropicTransport,
    StubTransport,
    propose,
    recommend,
    run_stability,
    validate_proposal,
)

payload = build_payload(config, state, replacement, rows)

# Draft night. Never raises on a bad proposal.
result = propose(payload, AnthropicTransport())  # -> Recommendation
result.proposal, result.violations, result.degraded, result.attempts

# Evals. A violation is the score, so it raises instead of degrading.
proposal = recommend(payload, StubTransport(recorded))
five = run_stability(payload, transport)  # None if coin_flip
```

**Use `propose`, not `recommend`, on the draft-night path.** `recommend` is the
strict eval entry point.

`Payload.to_dict` is still the serialised shape. Do not write another
serializer.

### `build_payload`

```python
def build_payload(
    config: LeagueConfig,
    state: DraftState,
    replacement: dict[str, Replacement],
    rows: Sequence[BoardRow],
) -> Payload
```

Caps the board, sets `hint_argmax_vols` to the capped-board max-VOLS id, and
appends `BOARD_CAPPED` if that code is not already present. Empty `rows`
raises `DataRefusal`.

If `config.slot is None`, the returned state has `next_user_pick`,
`picks_until_next`, and `between` set to `None` even when the caller filled
them. Do not guess a seat.

### `cap_board`

```python
def cap_board(
    rows: Sequence[BoardRow],
    *,
    pick_no: int,
    teams: int,
    rounds: int,
    needs: Mapping[str, Need],
) -> tuple[BoardRow, ...]
```

Union of three arms, ordered VOLS descending then `player_id`:

1. Top 50 by VOLS.
2. `position_depth(position)` per position: `2 + 2 * remaining` capped at 10,
   floor 2 when the position has no remaining starter need. K and DEF/DST get
   0 until the last two rounds *and* an empty starter slot.
3. Forward ADP window `[pick_no, pick_no + 2 * teams]`, plus the `teams`
   biggest fallers (`adp < pick_no`, lowest ADP first).

`needs` is `state.needs`, keyed by slot value. `rounds` is only used to work out
how many picks are left, for the K/DEF clause. It still does not use the seat.

Measured board size, 12-team league: 74 rows at pick 1, 79 at pick 40, 84 at
pick 100, 87 at pick 165 — roughly 4.8k–5.7k tokens. Before this change it was
96 at pick 1 and did not shrink or grow with the draft.

`remaining_need` and `position_depth` are exported for S6 to assert against.

### `recommend` / `run_stability`

```python
def recommend(payload: Payload, transport: Transport) -> Proposal
def run_stability(
    payload: Payload, transport: Transport
) -> tuple[Proposal, ...] | None
```

### `propose` — the draft-night path

```python
def propose(payload: Payload, transport: Transport) -> Recommendation
```

One call, one retry on any violation, then a fallback to `hint_argmax_vols`
with `degraded=True` and the violations attached. It never raises on a bad
proposal: the operator is on a pick timer, and a degraded pick beats no pick.
A transport failure still raises `PlatformError`.

Surface `result.violations` as banners when `result.degraded` is true. The
fallback `Proposal.why` already names the violation codes.

### `recommend` / `run_stability` — the eval path

```python
def recommend(payload: Payload, transport: Transport) -> Proposal
def run_stability(
    payload: Payload, transport: Transport
) -> tuple[Proposal, ...] | None
```

`recommend` sends `payload.to_dict()` once and raises `PlatformError` on any
violation — no retry, no degrade. `run_stability` sends five identical
payloads. If the first response has `coin_flip is True`, it stops and returns
`None`. Draft night does not call either.

### Transports

`StubTransport(response: dict | list[dict])` records each `complete` call on
`.calls`. A list walks one response per call and then repeats the last — that
is how a test drives the `propose` retry path.

`AnthropicTransport(client=None)` uses `anthropic.Anthropic()` when no client
is passed. Model id is `claude-opus-5`. It sets `thinking={"type": "adaptive"}`
and `output_config={"effort": "medium", "format": {...}}`, and
`max_tokens=16000`. It does not set `temperature` or `tools`.

### Validation

```python
def validate_proposal(
    payload: Payload, raw: object
) -> tuple[Proposal | None, tuple[Violation, ...]]
```

**It never raises.** `Proposal` is `None` only when the response cannot be read
as a proposal at all (bad shape, rec off the board, unknown flag). A readable
proposal that breaks a rule comes back *with* its violations, so the caller can
still show it.

Violation codes: `not_an_object`, `missing_key`, `extra_key`, `bad_player_id`,
`rec_off_board`, `bad_alternatives`, `alt_off_board`, `bad_slot`,
`illegal_slot`, `bad_coin_flip`, `bad_why`, `bad_flags`, `unknown_flag`,
`silent_vols_dissent`, `ecr_beyond_margin`.

`PlatformError` is now only the transport: HTTP failure, a refusal stop, a
`max_tokens` stop, a body that is not JSON. That is the host being broken, not
the model being wrong. `errors.py` is still frozen; `Violation` and
`Recommendation` are new `contracts.py` types.

## Spec vs this session

1. **ADP window is from `pick_no`, not from `next_user_pick`.** Unknown seat
   still caps by the next two rounds of the draft. Guessing a seat to size the
   window would violate the spec.
2. **`BOARD_CAPPED` is always on the payload** (unless the caller already put
   that code on `config.banners`). The list can be smaller than 50. The banner
   still says the list is a cap, so the model does not read scarcity off it.
3. **Call validation is the floor, not the XOR evals.** Silent VOLS dissent
   fails the call. Agreeing with the hint *and* setting `VOLS_DISSENT` does
   not fail the call; that XOR is S6. Missing `ECR_DISAGREE` when rec is not
   `ecr_best` does not fail the call; that XOR is S6. Rec beyond
   `ecr_best + margin` fails the call even with `ECR_DISAGREE`. Rec with no
   ECR skips the floor.
4. **Margin** is `teams` when `pick_no <= teams * rounds // 2`, else
   `2 * teams`. The `ecr_min` escape is implemented.
5. **No survival band.** The payload has no σ, band, or chance-to-last field.
   Wait-versus-take stays with the model.
6. **Temperature is not set.** The claude-api skill says sampling params
   return 400 on Opus 5. Tools are not passed. `budget_tokens` is also a 400
   on this model — `output_config.effort` is the depth lever, set to `medium`
   for the pick clock (the API default is `high`).
7. **A violation fails the call, not the run.** SPEC section 4 says so, and
   `propose` implements it. Only the eval path raises.
