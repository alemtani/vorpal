## Behaviour S8 cannot see from a skim

1. **Parse is not in this package.** Each method GETs JSON, then
   `SleeperHost().parse_*`. Shape failures raise `PlatformError` from parse.
   HTTP 4xx/5xx, connect/timeout, and invalid JSON also raise `PlatformError`.
   A failed call never returns a partial `Draft` / `League` / picks tuple.

2. **Error backoff lives in the client.** After a failure, the next HTTP
   call waits `backoff_seconds(consecutive_failures)` first. Success sets
   the count back to 0. S7 owns poll cadence (3s while `drafting`, else 15s
   until `complete`). If S7 also waits 5/15/45s, the wait doubles. Either
   let the client wait, or inject `sleep` that does not wait and do the
   wait in the loop. Do not do both.

3. **Rate limit is separate.** The client spaces HTTP calls by
   `60/1000` seconds. Cache hits on `/players` do not count. Stay under
   1000 calls/min without a token bucket.

4. **`/players` cache is 24 hours, rolling.** Envelope on disk:
   `{"fetched_at": <epoch seconds>, "players": <raw JSON>}`. Fresh cache
   skips HTTP. After 86400 seconds it fetches again. Corrupt cache is a
   miss, not a `PlatformError`. Fetch is at most once per day in the
   success path.

5. **`draft.status` is the state.** The client does not read `start_time`
   to decide pre-draft vs live. Observed values that parse through:
   `pre_draft`, `drafting`, `complete`, and `paused` (mid-draft fixture).
   Unknown statuses pass through as the string on the wire.

6. **No `active=true` filter.** Inactive rows stay in the dict.
   `search_rank` stays on the wire JSON. `Player` has no `search_rank` and
   no `adp`.

7. **`/players` has no `bye`.** That is S0. `Player.bye` is always `None`
   from this client.
