# S9 handoff

The evidence. Twelve golden cases and four regret fixtures. No `src/`.

Two directories, both self-contained:

| Path | Holds |
|---|---|
| `tests/golden/` | `cases.py` (the set), `boards.py` (builders), `README.md` (the honest limits) |
| `tests/regret/` | `replay.py` (the replay), `build.py` (regenerate), `fixtures/*.json`, `README.md` |

Read both READMEs before you use either. They say what the data does not
cover, which is the part that matters when a pass rate looks good.

## What S10 calls

`tests/` is not a package, so each directory puts itself on `sys.path`
in its own `conftest.py` and the modules import by bare name. That works
from a test under `tests/golden` or `tests/regret`. From `evals/`, add
the directory to `sys.path` first — the same two lines those conftests
use.

### Golden

```python
from cases import CASES, CASES_BY_NAME, GoldenCase

for case in CASES:
    proposal = call_the_model(case.payload)
    results = evaluate(case.payload, proposal, case.fixtures())
```

`GoldenCase` is `name`, `situation`, `payload`, `forbid`, `require`,
`why`, and `fixtures()` — which returns a `GateFixtures` with the two
golden fields set and every other field `None`. Fill in
`stability_ids` and `replacement_rank_delta` yourself:

```python
from dataclasses import replace

fixtures = replace(case.fixtures(), stability_ids=five_ids)
```

`case.why` is the sentence a human wrote. Put it in the report next to a
failure — a gate result with no reasoning beside it is a number nobody
can act on.

### Regret

```python
from replay import all_fixtures, load_fixture

fixture = load_fixture("snake_redraft_seat02_r03")
board_ids = [row.player_id for row in payload.board]
fixtures = fixture.gate_fixtures(board_ids)  # available_at_next only
```

Also `fixture.board_at_pick(board_ids)` for building the payload at that
pick, `fixture.actually_picked` for what the human took, and
`fixture.era` / `fixture.provenance` for the report.

**Pass the whole board in.** `available_at_next` filters the board
against the recorded picks. A player that room never took was available
the entire time, and intersecting against a drafted set instead would
call him gone.

## What the sets are for, and what they are not

Spec section 8 says the small human golden set is the main eval limit.
Being honest about its size is part of shipping it, so:

- **12 golden cases.** Every verdict is a floor — a mistake that needs
  no model to spot. Nothing here rewards a good pick.
- **`argmax_vols` fails 3 of the 12.** That is the ceiling on what this
  set can tell you about the model: three cases of separation. A pass
  rate on the other nine is not evidence the model is doing anything, and
  the report should not read as if it were.
- **4 regret fixtures across 3 drafts** (two are the same draft at two
  picks). Nothing here supports fitting a survival model. Spec section 7
  gates VONA on the regret set being large enough; four seats is not
  close.

`tests/golden/README.md` has the full list of what is not covered:
contested picks, real distributions, format breadth, missing-data
boards, four of the six flags, everything after the draft.

## Three findings

**1. `bye_hole` cannot see a bye stack.** The gate compares alternatives
only in the recommendation's own bye week. With one receiver slot empty
and one receiver rostered, *any* receiver added leaves that slot empty
in the week he is off, and any different-bye receiver on the board would
have filled it. So the gate fails both candidates, symmetrically.

The `bye_stack` golden case separates them easily by reading the whole
weekly vector: three starters are already off in week 9, so a fourth
week-9 player buys a hole in the worst week of the season while the
bye-5 receiver buys one in a week that is otherwise full. The gate sees
one week at a time and cannot make that comparison.

Pinned by `test_bye_hole_gate_cannot_see_a_stack`. Not a code bug and
not fixed here — S9 does not touch `src/`. If S10's table shows
`bye_hole` failing nearly everything, this is why, and it is a spec
question (section 5 defines the gate exactly as built) rather than a
patch.

**2. A kicker cannot reach a round-2 board.** Spec section 4 sets
`depth = 0` for K and DEF until the last two rounds, so on a real
round-2 payload a kicker is not on the board and a kicker recommendation
fails `schema`, not `golden_forbid`. The `kicker_round_two` case puts
one on the board deliberately: the forbid gate is the second line, and it
is the line that still holds if the cap regresses. Same for
`defense_round_three`. Read those two as defence in depth, not as boards
the payload builder would produce.

**3. The frozen-board replay keeps our own pick available.** We
substitute our recommendation and leave the other eleven teams' recorded
picks unchanged, so in the counterfactual nobody drafted the player the
human actually took. `available_at_next` includes him. That is correct
for the gate and it is also the clearest statement of why this is a
floor on wait-or-take rather than a simulation.

## Regenerating the regret fixtures

```sh
uv run python tests/regret/build.py
uv run pytest tests/regret
```

The committed JSON is derived from `tests/fixtures/sleeper/picks_*.json`
and the test rebuilds and compares it byte for byte. Hand-editing a file
fails the suite, which is the point: a record you can edit is not a
record.

Adding a seat is a dict in `SPECS` in `build.py`. Adding a *draft* means
recording it first with `tools/record_fixtures.py`, and the redaction
rule is absolute — if a draft cannot be redacted it does not get
committed.

## What S9 did not do

- No `src/` at all. No new gate, no change to an existing one.
- No eval run and no report. That is S10.
- No `stability_ids` — those are five real model calls, which S9 has no
  transport for.
- No `replacement_rank_delta` — that is S4's arithmetic over the full
  pool, not something a hand-written board can assert.
- No `dated_points` / `user_lineup` / `policy_lineup`, so the `replay`
  gate is `NOT_PERFORMED` on everything here. A dated projections file
  from the season a regret fixture was drafted in would fill it; we do
  not have one.
- No new recorded drafts. The four fixtures come from the three
  completed drafts the seed already recorded and redacted.
