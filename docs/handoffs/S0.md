# S0 handoff

Seed. Types, errors, fixtures, CI. No feature logic.

## What other sessions call

Generic types live in `vorpal.contracts`. The host adapter is
`vorpal.platform.LeagueHost`. v1 ships `SleeperHost`, which parses fixture
dicts (no HTTP). S1 adds transport on top of that parse.

```python
from vorpal.platform import LeagueHost, SleeperHost
```

Callers take `LeagueHost`, not `SleeperHost`. ESPN later is another subclass.

Also: `Payload.to_dict`, `Proposal.to_dict`, `Banner.to_dict`.

```python
from vorpal.contracts import (
    AdpVariant,
    IDP_SLOTS,  # ("DL", "LB", "DB", "IDP_FLEX")
    Banner,
    BoardRow,
    Draft,
    DraftState,
    EcrRow,
    Host,
    LeagueFormat,
    Flag,
    Gate,
    GateOutcome,
    GateResult,
    League,
    LeagueConfig,
    OverrideRow,
    Payload,
    Pick,
    Player,
    Proposal,
    Replacement,
    Seat,
    Slot,
    SlotCounts,
    StatRow,
    User,
    WeeklyCell,
)
from vorpal.errors import (
    DataRefusal,
    PlatformError,
    UnsupportedLeague,
    UserRefusal,
    VorpalError,
)
```

S1: HTTP client that returns `SleeperHost().parse_*` results. Cache, backoff.
S3 should return `LeagueConfig`, `Seat`, and `Banner`s, or raise.
S2 should return `StatRow`, `EcrRow`, `OverrideRow`.
S4 should return `Replacement`, `WeeklyCell`, `BoardRow` fields `points` /
`vols` / `delta_starter_points`.
S5 should build `Payload` and parse a `Proposal`.
S6 should return `GateResult`.

If a generic type or `LeagueHost` method must change, open a small PR
against `contracts.py` / `platform/`, then rebase. Do not fork the type.

## Contract types and fields

Every type is a frozen dataclass with `slots=True`, except the enums.

### Enums

- `Host`: `sleeper`, `espn` (reserved; no adapter yet)
- `LeagueFormat`: `redraft`, `keeper`, `dynasty`, `unknown`
- `AdpVariant`: `2qb`, `ppr`, `half_ppr`, `std`
- `Slot`: `QB`, `RB`, `WR`, `TE`, `K`, `DEF`, `FLEX`, `SUPER_FLEX`, `OP`,
  `BN`, `WRRB_FLEX`, `REC_FLEX`, `DL`, `LB`, `DB`, `IDP_FLEX`
- `Flag`: `ECR_DISAGREE`, `BYE_STACK`, `POSITION_RUN`, `EMPTY_STARTER`,
  `UPSIDE`, `VOLS_DISSENT`
- `Gate`: `schema`, `golden_forbid`, `golden_require`, `vols_dissent`,
  `ecr_dissent`, `ecr_sanity`, `bye_hole`, `stability`, `vols_invariant`,
  `regret`, `replay`
- `GateOutcome`: `PASS`, `FAIL`, `NOT_PERFORMED`

There is no `Slot.DST`. The wire is `DEF`.

### `Banner`

`code: str`, `message: str`

### `Seat`

`user_id: str`, `slot: int`, `roster_id: int | None`

### `User`

`user_id: str`, `username: str`, `display_name: str`, `is_bot: bool`

### `Player`

`player_id: str`, `host: Host`, `first_name: str`, `last_name: str`,
`name: str`, `position: str`, `team: str | None`,
`fantasy_positions: tuple[str, ...]`, `active: bool | None`,
`status: str | None`, `injury_status: str | None`, `years_exp: int | None`,
`number: int | None`, `bye: int | None`

One id plus which host it belongs to. Sleeper `yahoo_id` / `espn_id` /
`search_rank` stay on the wire JSON. They are not domain fields. `bye`
is optional because `GET /players/nfl` does not carry it.

### `StatRow`

`player_id: str`, `source: str`, `week: int | None`, `season: str`,
`stats: dict[str, float]`, `adp: float | None`, `gp: float | None`,
`market_only: bool`

`stats` is counting keys only. `pts_*` must never appear here. Raw Sleeper
projection files still have `adp_ppr` / `adp_2qb` / … — ingest picks one
via `AdpVariant` and `ADP_WIRE_KEYS` on the Sleeper adapter. `adp` on this
row is already the chosen number.

### `EcrRow`

`player_id: str`, `name: str`, `team: str | None`, `position: str`,
`bye: int | None`, `rank_ecr: int`, `rank_min: int`, `rank_max: int`,
`rank_std: float`

`player_id` is the **host** id after join. Yahoo ids stay on the FantasyPros
JSON.

### `OverrideRow`

`player_id: str`, `stats: dict[str, float]`, `adp: float`,
`adp_stdev: float | None = None`, `name: str | None = None`,
`team: str | None = None`, `pos: str | None = None`

### `Pick`

`draft_id: str`, `player_id: str`, `picked_by: str`, `roster_id: int | None`,
`round: int`, `draft_slot: int`, `pick_no: int`, `is_keeper: bool | None`,
`position: str | None`, `team: str | None`, `first_name: str | None`,
`last_name: str | None`

`picked_by` is `""` for CPU. `roster_id` is `null` on standalone mocks.
`is_keeper` is `null` on every recorded pick.

### `SlotCounts`

`qb, rb, wr, te, k, defense, flex, super_flex, op: int = 0`,
`bn: int | None = None` (None means the host omitted bench).

Sleeper `slots_def` maps to `defense`.

### `Draft`

`host: Host`, `draft_id: str`, `type: str`, `status: str`, `sport: str`,
`season: str`, `season_type: str`, `league_id: str | None`,
`start_time: int | None`, `teams: int`, `rounds: int`,
`pick_timer: int | None`, `reversal_round: int`, `slot_counts: SlotCounts`,
`scoring_label: str | None`, `draft_order: dict[str, int] | None`,
`slot_to_roster_id: dict[int, int]`

`SleeperHost` coerces wire string keys on `slot_to_roster_id` to ints.
`slots_k` / `slots_def` may be `0`. `slots_bn` may be absent (`bn is None`).

### `League`

`host: Host`, `league_id: str`, `draft_id: str`, `season: str`, `status: str`,
`sport: str`, `season_type: str`, `total_rosters: int`,
`roster_positions: tuple[Slot, ...]`, `scoring: dict[str, float]`,
`format: LeagueFormat`, `max_keepers: int`, `taxi_slots: int`,
`num_teams: int`

Sleeper `settings.type` 0/1/2 maps to redraft/keeper/dynasty.

### `LeagueConfig` (resolved; S3 output)

`teams: int`, `rounds: int`, `slots: tuple[Slot, ...]`,
`scoring: dict[str, float]`, `scoring_summary: str`,
`banners: tuple[Banner, ...]`, `slot: int | None = None`,
`draft_id: str = ""`, `league_id: str | None = None`,
`scoring_league_id: str | None = None`, `season: str = ""`,
`draft_type: str = "snake"`, `status: str = "pre_draft"`,
`pick_timer: int | None = None`, `reversal_round: int = 0`,
`adp_variant: AdpVariant = PPR`, `ecr_scoring: str = "PPR"`

### `Need`

`filled: int`, `required: int`

### `RosterPlayer`

`player_id: str`, `name: str`, `position: str`, `bye: int | None`

### `WeeklyCell`

`week: int`, `starter_points: float`, `empty: tuple[Slot, ...]`

### `RecentPick`

`player_id: str`, `position: str`, `pick_no: int`

### `BetweenTeam`

`slot: int`, `roster: dict[str, int]`, `needs: dict[str, Need]`

### `DraftState` (payload `state`, not the raw draft)

`pick_no: int`, `user_roster: tuple[RosterPlayer, ...]`,
`needs: dict[str, Need]`, `weekly: tuple[WeeklyCell, ...]`,
`recent: tuple[RecentPick, ...]`, `next_user_pick: int | None = None`,
`picks_until_next: int | None = None`,
`between: tuple[BetweenTeam, ...] | None = None`

Omit the three optional fields when the seat is unknown. `Payload.to_dict`
drops them.

### `Replacement`

`player_id: str`, `points: float`

Payload field `replacement` is `dict[str, Replacement]` keyed by position.

### `BoardRow`

`player_id: str`, `name: str`, `position: str`, `points: float`, `vols: float`,
`delta_starter_points: float`, `adp: float`, `legal_slots: tuple[Slot, ...]`,
`bye: int | None = None`, `gp: float | None = None`, `ecr: int | None = None`,
`ecr_min: int | None = None`, `ecr_max: int | None = None`,
`ecr_std: float | None = None`

### `Payload`

`config: LeagueConfig`, `state: DraftState`,
`replacement: dict[str, Replacement]`, `hint_argmax_vols: str`,
`board: tuple[BoardRow, ...]`

`to_dict()` key set is exactly SPEC.md section 4.

### `Proposal`

`player_id: str`, `alternatives: tuple[str, ...]`, `slot_filled: Slot`,
`coin_flip: bool`, `why: str`, `flags: tuple[Flag, ...]`

### `GateResult`

`gate: Gate`, `outcome: GateOutcome`, `reason: str | None = None`

## Errors

`VorpalError.message` is safe for stderr.

| Class | When |
|---|---|
| `UnsupportedLeague` | Permanent format refusal |
| `DataRefusal` | Fixable by a better file |
| `PlatformError` | API / host |
| `UserRefusal` | Operator / seat |

Do not collapse them.

## Spec vs recorded bytes

These contradict the spec prose or the old AGENTS.md. Trust the bytes.

1. **`GET /players/nfl` has no bye field.** SPEC.md section 3 says it carries
   `bye`. It does not, on a full 12k-player dump. `Player.bye` is optional
   for a later join (FantasyPros `player_bye_week`). Do not invent bye weeks
   from `/players`.
2. **Defense is `DEF`, not `DST`.** Roster list, draft `slots_def`, player
   `position`.
3. **`SUPER_FLEX`**, not `SUPERFLEX`. Draft settings key `slots_super_flex`.
4. **`league_id` is JSON `null`** on mocks, not omitted.
5. **`roster_id` on a pick may be `null`** and `picked_by` may be `""` on
   mocks. `is_keeper` is `null`, not `false`.
6. **Draft `status` includes `paused`.** Spec lists `pre_draft`, `drafting`,
   `complete`. The mid-draft fixture is `paused`.
7. **`settings.type == 0`** is redraft, observed. Recorded redrafts also have
   `max_keepers: 1`. That is not a refusal.
8. **Projections:** `company` is `rotowire` on every row. `week` is `null`.
   `game_id` is `"season"`. Counting keys plus `gp`, `adp_*` (including
   `adp_idp`, `adp_dynasty_*`; v1 ADP variant keys are `adp_2qb` / `adp_ppr`
   / `adp_half_ppr` / `adp_std` only). `pts_ppr` / `pts_std` / `pts_half_ppr`
   are present on the wire. There is no `adp_2qb_ppr`. Nested `player` has
   no bye.
9. **Sleeper `yahoo_id`** is an int or null. Many K/DEF rows have null.
   FantasyPros `player_yahoo_id` is a string. DST yahoo ids exist on FP
   (e.g. `100034`) while Sleeper `DEF` rows often have `yahoo_id` null —
   join on yahoo will miss DST unless S2 maps another way.
10. **FantasyPros `position` is required.** Valid: `QB, RB, WR, TE, K, OP,
    FLX, DST, …`. `ALL` returns 400. `FLX` returned zero rows in PPR.
    There is no overall list on the free public API. `ecr_best` as “min
    overall ECR” cannot be read from these fixtures; positional
    `rank_ecr` is what we have. `player_bye_week` is present (string).
    `rank_std` is present (string). `EcrRow` fields did not change.
11. **`slot_to_roster_id` keys are strings on the wire.** `SleeperHost`
    coerces them to `dict[int, int]`.
12. **Scoring weights** can be IEEE noise (`0.10000000149011612`). Keep them
    as recorded floats.
13. **Picks carry `reactions`** keyed by user id. Fixtures rewrite those keys.
    Ignore reactions in v1.

## What S0 did not do

- No HTTP client (S1). No ingest, resolve, VOLS, board, or CLI.
- No ESPN adapter. `Host.ESPN` is reserved.
- No eligibility table (S3).
- No parse functions (S1 / S2).
