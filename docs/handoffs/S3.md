Resolve. Slots, scoring source, seat, ADP/ECR variant, refusals, banners.
No network. No contract change.

`legal_slots(position, roster) -> tuple[Slot, …]` is the spec table applied
to a resolved roster. `eligible_positions(Slot.BN) is None` means any
position. BN is last.

S8: fetch projections once, collect counting keys (no `pts_*`, no `adp_*`),
then call `resolve`. `stat_columns=None` skips the unknown-key banner.
LeagueConfig is frozen, so you cannot add that banner later.

S2: take `resolved.config.adp_variant` and `resolved.ecr_position`. Do not
read `draft.scoring_label`. There is no `adp_2qb_ppr`. ECR scoring param
is `resolved.config.ecr_scoring` (`PPR` / `HALF` / `STD`) from `rec`.

S5: `config.slot is None` and `seat is None` mean the seat is unknown.
Omit `next_user_pick`, `picks_until_next`, and `between`. Do not guess.

## Banner codes

| code | when |
|---|---|
| `keepers_possible` | redraft and `max_keepers > 0` |
| `slots_from_mock` | `draft.league_id` is null |
| `scoring_borrowed` | same; message names the borrowed league and says they may disagree |
| `rec_nonstandard` | `rec` is not exactly `0`, `0.5`, or `1` |
| `unknown_scoring_keys` | nonzero scoring key not in `stat_columns`; keys are listed |
| `unstartable_scoring` | classified nonzero keys with no startable slot; one line |

Zero-weight keys are not reported. Negative weights are nonzero.

## Refusals

| class | when |
|---|---|
| `UnsupportedLeague` | keeper / dynasty / unknown format, taxi, IDP slots, auction, linear, `reversal_round != 0` |
| `UserRefusal` | complete order without the operator; partial order without the operator and no `explicit_slot`; mock with no `scoring_league` |
| `DataRefusal` | attached draft with no `league`, or `league.league_id` ≠ `draft.league_id` |

`max_keepers > 0` on redraft is not a refusal.

## Rules that are easy to miss

- Slots: `league.roster_positions` when the draft belongs to a league;
  else `Draft.slot_counts`. Infer BN only when `slot_counts.bn is None`
  and the league list did not fire: `max(0, rounds − starter slots)`.
  A borrowed scoring league never overrides slots.
- Format refusals run on the scoring source (attached league, or the
  borrowed league on a mock).
- Seat matches `operator.user_id` in `draft_order`. Not `picked_by`.
  `draft_order is None` or `{}` is unset: proceed, `seat is None`.
  Complete means slots `1..teams` all appear as values. A complete miss
  refuses even if `explicit_slot` is set. A partial miss accepts it.
- ADP: `SUPER_FLEX` / `OP` / 2+ `QB` slots → `TWO_QB` and ECR `position=OP`.
  Else `rec >= 0.75` → PPR; `rec >= 0.25` → HALF; else STD.
- `metadata.scoring_type` / `Draft.scoring_label` is a label. The mock
  fixture is `half_ppr` and still resolves to PPR when the borrowed
  league has `rec=1`.

## Spec vs this session

- `LeagueConfig` has no `ecr_position`. It lives on `Resolved` so this
  session did not fork contracts.
- `SlotCounts` has no IDP fields. IDP refusal only fires from
  `league.roster_positions`. A mock cannot surface `slots_dl`.
- The S8 prompt listed resolve before projections. Unknown-key banners
  need columns. Fetch projections first; pass `stat_columns`.

## What S3 did not do

- No `next_user_pick` arithmetic. That is payload state (S5).
- No HTTP. Callers pass `Draft`, `League`, `User`, `Pick`.
- No contract PR.
