### Scoring

```python
points = score_player(position, stats, scoring)  # float
score_skill(stats, scoring, position=pos)  # RB/WR/TE share this
unmatched_scoring_keys(scoring, columns)  # tuple[str, ...]
```

`stats` is counting keys only. `score_player` never reads `pts_ppr` /
`pts_std` / `pts_half_ppr`. A fixture QB can have `pts_ppr` equal to the
counting total; that is coincidence. Zero the counting keys and the score
is 0.

`unmatched_scoring_keys` lists every nonzero scoring key with no column,
plus any fantasy-point key. Zero-weight keys do not need a column. S3
itemizes; the operator proceeds (key = 0) or supplies an override. S4
does not raise.

Longer prefix wins: `pass_int` is QB, `int` is DST. Exact `rec` is skill
(the `rec_` prefix does not match `rec` itself). `pass_def` is DST, not
`pass_*`.

`bonus_rec_te` applies only to TE. If the bonus column is absent, the
count is `rec`. Same for `bonus_rec_rb` / `bonus_rec_wr`.

### VOLS

```python
result = compute_vols(players, slots, teams) -> VolsResult
# result.values              tuple[PlayerValue, ...]  vols desc, then player_id
# result.replacement         dict[str, Replacement]   first unabsorbed per pos
# result.replacement_ranks   dict[str, int]           1-indexed positional index
# result.pass1_replacement_ranks
# result.value_by_id()[id].vols / .points
```

Two passes exactly. Pass 1 ranks by points and fills. Pass 2 re-ranks by
that VOLS and fills once more. Stop.

Fill order: dedicated slots (`teams × count`), then flex most-restrictive
first (WRRB_FLEX / REC_FLEX, then FLEX, then SUPER_FLEX / OP). BN is not
absorbed. Market-only rows are excluded from the pool, the ranking, and
`values`.

`vols = points − replacement[position].points`. If every player at a
position is absorbed, that position is omitted from `replacement` and the
baseline is 0.

`hint_argmax_vols` is `result.values[0].player_id` among players still
available. This module does not know who is drafted.

### Weekly vector and delta

```python
week_vector(points, *, gp=None, bye=None, out_weeks=frozenset())
    -> tuple[float, ...]          # length 18, weeks 1..18

fill_starters(roster, slots) -> tuple[WeeklyCell, ...]
    # WeeklyCell.week, .starter_points, .empty (startable slots with no
    # positive-rate player). BN is never in empty.

delta_starter_points(roster, candidate, slots) -> float
    # sum over 18 weeks of (starter_points with candidate
    # − starter_points without)
```

Rate is `points / 17`, or `points / gp` when `gp` is present. Bye and
`out_weeks` are 0. `gp < 17` does not invent which weeks are missed: pass
`gp` through on the board row. A served suspension is
`out_weeks=frozenset(range(1, n + 1))`. S4 does not parse injury notes.

A player with rate 0 that week does not fill a startable slot. That is how
a bye hole shows up in `empty`.

`vols` is global. `delta_starter_points` is vs this roster. The same
player keeps the same vols against zero RBs or four; the delta changes.

## VOLS invariant (S6)

```python
extra = hypothetical_replacement_ranks(players, slots, teams, result)
shifts = replacement_rank_shifts(result.replacement_ranks, extra)
# FAIL iff any shift > MAX_REPLACEMENT_RANK_SHIFT (2)
```

This is an extra fill ranked by the solver's VOLS. It is not a third
solver pass. Do not change the solver to make the eval pass. A failure is
a model problem: `GateOutcome.FAIL`.

`replacement_rank_shifts` only compares positions present in both maps.

`@pytest.mark.invariant` is the marker. It already exists in pytest
config.

## Spec vs this code

1. **Replacement rank move on pass 2.** With unique points, pass 2 often
   keeps the same absorbed set as pass 1 (flex assignment reinforces).
   Superflex still matters: pass 1 puts extra QBs into SUPER_FLEX, so QB
   replacement is deeper than `teams × qb_slots + 1`. Ranking by the
   resulting VOLS is not ranking by points. The "pass 2 moves ranks" test
   asserts that reorder. The invariant compares a hypothetical extra fill
   to pass 2, not pass 1 to pass 2.
2. **`/players` has no bye.** `ScoredPlayer.bye` is optional. Join it
   upstream (FantasyPros `player_bye_week`).
3. **Defense is `DEF`.** `score_player("DST", ...)` maps to DEF. Slot
   code is `Slot.DEF`.
4. **K/DST flat baseline** when a slot exists and the file has no rows is
   S2/S5. S4 scores the rows it is given.
5. **Known-out weeks** are an input (`out_weeks`). S4 does not infer
   suspension length from `injury_status`.

## What S4 did not do

- No payload assembly, no board cap, no `hint_argmax_vols` picker (S5).
- No gate objects (S6). The rank-shift helpers are the VOLS invariant
  input.
- No ingest, no Sleeper client, no CLI.
- `legal_slots` stays with S3/S5. Fill eligibility lives in
  `vorpal.valuation.slots.ELIGIBLE` if you want one copy.
