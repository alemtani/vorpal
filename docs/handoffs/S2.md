## What S8 calls

```python
from vorpal.ingest import load_forecast, load_stat_rows, clear_caches
from vorpal.contracts import AdpVariant

stat_rows, ecr_rows, banners = load_forecast(
    season,                          # draft.season, e.g. "2026"
    adp_variant,                     # from S3; do not compute it here
    ecr_scoring=config.ecr_scoring,  # "PPR" | "HALF" | "STD"
    superflex=superflex,             # SUPER_FLEX / OP / 2+ QB slots
    sleeper_players=raw_players,     # RAW GET /players/nfl dict
    override_path=path_or_none,      # optional CSV
    fp_api_key=os.environ.get("FANTASYPROS_API_KEY"),
    min_interval_s=1.1,              # live FP is 1 call/s; tests use 0
)
```

`sleeper_players` must be the wire JSON. Parsed `Player` has no `yahoo_id`.
Keep the raw `/players` payload next to `SleeperHost.parse_players`.

Returns:

- `tuple[StatRow, ...]` — counting keys only. `adp` is already the chosen
  variant. `market_only=True` means ADP (or empty stats) and no counting
  keys; S4 excludes those from VOLS.
- `tuple[EcrRow, ...]` — host `player_id` after join. Empty if FP is down.
- `tuple[Banner, ...]` — surface before the board.

Banner codes:

| code | when |
|---|---|
| `ecr_missing` | no API key, or FP HTTP/JSON failure |
| `ecr_join_miss` | FP row could not join; count in the message |
| `ecr_team_mismatch` | joined on name+pos; teams differed |
| `projections_override` | host was not used; CSV supplied stats+ADP |

Parse-only entry points (fixtures, no HTTP):

```python
from vorpal.ingest import (
    parse_projections,   # payload, AdpVariant -> tuple[StatRow, ...]
    parse_ecr,           # payloads, sleeper_players -> (EcrRow..., Banner...)
    parse_override,      # csv text -> tuple[OverrideRow, ...]
    fetch_projections,   # season; process-cached
    fetch_ecr,           # season, scoring=, superflex=, sleeper_players=, fp_api_key=
    load_override,       # path -> tuple[OverrideRow, ...]
    load_stat_rows,      # projections or override, then mapping gate
)
```

`load_stat_rows` is the stats half of `load_forecast`. It runs the 98%
mapping gate. `AdpVariant` maps through `ADP_WIRE_KEYS` on
`vorpal.platform.sleeper`. There is no `adp_2qb_ppr`.

Process caches: one projections fetch per season, one ECR fetch per
`(season, scoring, superflex)`. Never poll. Tests call `clear_caches()`.

## Mapping

Match `player_id` first. Then name+pos+team. Then name+pos with a team
mismatch flag. DST/DEF are the same position. Ambiguous name+pos is a miss.

Rate is on the top 300 by ADP (lowest first). Under 98% raises
`DataRefusal`; the message *is* the report. 294/300 passes. 293/300
refuses. Rows with no ADP are not in the 300.

Override path never name-matches. Projections path may.

Recorded `tests/fixtures/sleeper/players.json` is a subset. Mapping it
against `projections/season_regular.json` is ~87%. E2E fixtures must
supply a player map that includes the projected ids, or the gate fires.

## Spec vs this session

1. **`pts_allow_*` stays.** League scoring uses those DST buckets. The
   hard rule strips `pts_ppr` / `pts_std` / `pts_half_ppr` and any other
   `pts_*` total. A test fails if a non-`pts_allow` `pts_*` key reaches
   `StatRow.stats`.
2. **ECR join miss is not the 98% gate.** A miss omits that row and
   banners the count. FP down banners `ecr_missing` and returns no ECR.
   Neither blocks a draft.
3. **Yahoo first, then name.** Sleeper DEF `yahoo_id` is null. FP DST
   yahoo ids do not join. Name+pos+team recovers them (`Houston Texans`
   → `HOU`). FP `JAC` vs Sleeper `JAX` is name+pos with
   `ecr_team_mismatch`.
4. **Superflex ECR** fetches `OP`, `K`, `DST`. 1QB fetches
   `QB, RB, WR, TE, K, DST`. Scoring query is `PPR` / `HALF` / `STD`.
5. **Projections down + no override** is `DataRefusal`, not
   `PlatformError`. Transport failure is `PlatformError` at
   `fetch_projections`; `load_stat_rows` converts it when there is no
   CSV. Mixed/non-rotowire company is `DataRefusal` (bad file).
6. **Company is `rotowire` only.** A single other company refuses. Mixed
   companies refuse.
