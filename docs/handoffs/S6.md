# S6 handoff

Evals. Eleven binary gates, three baseline policies, ADP-order sampler,
four-column report. Zero network. No LLM-as-judge.

This package does not import `vorpal.valuation`. The board is capped, and
replacement ranks need the full pool, so the VOLS-invariant gate takes rank
deltas as a fixture that S4 produces.

## What each gate asks

Read this table first. The rest of the file is mechanics.

| Gate | Asks | Fails when |
|---|---|---|
| `schema` | Is the answer well-formed? | It names a drafted player, or starts a kicker at RB. |
| `golden_forbid` | Did it make a plainly wrong pick? | The pick is in a set a human wrote for this board — a kicker in round 2. |
| `golden_require` | Did it see the right players at all? | Neither the pick nor any alternative is in the must-name set. |
| `vols_dissent` | If it left our VOLS pick, did it say so? | It dissented silently, or flagged dissent while agreeing. XOR. |
| `ecr_dissent` | Same, against expert consensus. | Same shape, with `ECR_DISAGREE`. |
| `ecr_sanity` | Defensible reach or off the map? | The pick sits more than a round (two, late) past the best player left. |
| `bye_hole` | Empty starter slot on the pick's own bye? | A different-bye alternative would have filled a slot the pick leaves empty. |
| `stability` | Is this judgment or a dice roll? | Five reruns on an identical payload, and no player appears three times. |
| `vols_invariant` | Has our own arithmetic settled? | A third VOLS pass would move some position's replacement by more than two ranks. |
| `regret` | Could we have had both names? | The pick would have kept until our next turn; an alternative would not. |
| `replay` | Better roster than the human's? | Lower projected-lineup sum on the same draft-day numbers. |

Three of the eleven judge us, not the model. `schema` catches malformed
output, and `vols_invariant` and `replay` measure the tool's own numbers.
The other eight are the model on trial.

## Adding a gate

Four edits, in order:

1. Add the member to `Gate` in `contracts.py`. Enum order is report order.
2. Write the function in `gates.py` with the shared
   `(payload, proposal, fixtures)` signature. Ignore what you do not need.
3. Add the `(Gate.X, fn)` pair to `GATES`. The module-level `assert` fails
   at import if the registry and the enum drift apart.
4. Export it from `evals/__init__.py` and list it in the docstring table.

If it needs an input the payload cannot carry, add an
`X | None = None` field to `GateFixtures` and skip when it is `None`.

`GateFixtures` fields. `None` means that gate is `NOT_PERFORMED`. An empty
collection is present and the gate still runs.

| Field | Gate | Meaning |
|---|---|---|
| `forbid: frozenset[str] \| None` | golden_forbid | Player ids that must not be rec |
| `require: frozenset[str] \| None` | golden_require | Rec or an alternative must be in this set |
| `stability_ids: tuple[str, ...] \| None` | stability | Exactly five `player_id`s from identical payloads |
| `replacement_rank_delta: dict[str, int] \| None` | vols_invariant | Position → how far a hypothetical extra VOLS pass moved replacement rank |
| `available_at_next: frozenset[str] \| None` | regret | Ids still undrafted at the user's next pick |
| `dated_points: dict[str, float] \| None` | replay | Player id → projected season points from a dated file |
| `user_lineup: tuple[str, ...] \| None` | replay | User's starters (dated points, not actuals) |
| `policy_lineup: tuple[str, ...] \| None` | replay | Policy's starters on the same dated file |

A missing proposal (`None`) skips every gate.

Pass rate is `passes / (passes + fails)`. Skips are not a zero. When model
and `argmax_vols` post the same rate, or either did not run, the table prints
`NO DISCRIMINATING POWER` on that row.

## Spec calls that were ambiguous

**VOLS invariant.** The board is capped. Replacement ranks need the full
pool, which this package does not have. S4's hypothetical extra pass belongs
in a fixture: `replacement_rank_delta`. Fail iff any `abs(delta) > 2`. Empty
dict is a pass. No fixture is `NOT_PERFORMED`.

**Bye hole.** Adding a player to a full-roster fill cannot create a new empty
versus the current roster. The gate compares rec against other *board*
players with a different bye, on `rec.bye`. Fail if rec leaves a startable
slot empty that an alt would fill. Listed `alternatives` are not the search
set — omitting a different-bye player must not save the pick. No different-bye
player on the board is a pass. Rec with no bye, or rec off the board, is
`NOT_PERFORMED`.

**`ecr_best`.** Min of `BoardRow.ecr` across the whole board. Not positional.
S0 already noted that free-tier FantasyPros fixtures are positional lists.
Whoever fills the board (S2/S5) must put overall ranks on the row. This
package does not re-join ECR.

**First half.** `pick_no * 2 <= teams * rounds`. Margin is `teams` on that
side, else `2 * teams`.

**Dissent gates are XOR.** Agreeing with the hint and setting `VOLS_DISSENT`
fails, same as silent dissent. Same shape for ECR and `ECR_DISAGREE`. No ECR
on the board skips ECR dissent. No ECR on rec skips ECR sanity. Rec without
ECR while others have one is not `ecr_best`; the flag must be set.

**ECR sanity** is a floor: `ecr(rec) <= ecr_best + margin` or
`ecr_min(rec) <= ecr_best + margin`. Past both fails. The flag does not save
it.

**Regret.** Fail iff rec was still available at the next user pick *and* a
listed alternative was not. Rec gone is a pass. Both survived is a pass.
Empty alternatives cannot fail this gate. No survival model.

**Replay.** Compare projected-lineup sums on the same dated stats. Actuals
are luck and are never an input. A player missing from `dated_points` counts
as 0. Need all three of `dated_points`, `user_lineup`, `policy_lineup`.

**Stability.** `coin_flip` skips. Otherwise need exactly five ids. Pass if
any id appears at least three times.

**Golden sets are player ids for one payload.** "Kicker in rounds 1–3" is
S9 putting that kicker in `forbid` on an early-round board. This gate is set
membership, not a rule engine.

**Baselines** set only the two XOR flags. They pick a single alternative
(next board row). `slot_filled` is the first legal starter that still has a
need. `ecr_follow` with no board ECR falls back to `argmax_vols`.

## What S6 did not do

- No eval run over recorded drafts. That is S10.
- No golden or regret data files. That is S9.
- No call into valuation. Rank deltas are S4's to produce when it exists.
- No network, no model transport, no judge prompt.
