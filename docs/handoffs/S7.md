# S7 handoff

HTML board and the draft-night poll loop. No CLI. No network of its own.

## What S8 injects

```python
from pathlib import Path
from vorpal.board import Frame, render, run_loop, write_html
from vorpal.contracts import Banner, Draft, Pick, Payload, Proposal
```

### `render` — pure, does not write

```python
html: str = render(
    payload: Payload,
    proposal: Proposal,
    age_seconds: float,
    banners: tuple[Banner, ...],  # extra banners only
) -> str
```

The page is one self-contained HTML string. Meta-refresh is 3s when
`payload.config.status == "drafting"`, else 15s. Config banners on the
payload are always shown. Pass loop-only extras in the fourth argument
(`ecr_missing`, poll errors). Do not pass `payload.config.banners` again.

Age ≥ 15s degrades the page and adds a loud `stale_data` banner. Age ≥
`payload.config.pick_timer` greys the board (not the banners) and adds
`greyed_out`. Grey-out is skipped when `pick_timer` is `0` or `None`.
Degraded and greyed pages say the board is not current.

`write_html(path, html)` does a same-directory replace (`board.html.tmp` then
rename). Use it for a one-shot page. The loop already calls it.

### `run_loop` — the poll

```python
run_loop(
    client,          # DraftPollClient: get_draft() / get_picks() only
    recompute,       # (Draft, tuple[Pick, ...]) -> Frame
    output_path,     # Path | str  e.g. Path("board.html")
    *,
    now,             # () -> float. Production: time.monotonic
    sleep,           # (seconds: float) -> None. Production: time.sleep
    should_stop=None # () -> bool. None means run until draft.status == "complete"
) -> None
```

There is no default clock. You must pass `now` and `sleep`.

`Frame` is the recompute return type:

```python
@dataclass(frozen=True, slots=True)
class Frame:
    payload: Payload
    proposal: Proposal
    banners: tuple[Banner, ...]
```

### Client shape

S1 will likely take a `draft_id`. The loop does not. Bind it in the CLI:

```python
class BoundClient:
    def get_draft(self) -> Draft:
        return sleeper.get_draft(draft_id)

    def get_picks(self) -> tuple[Pick, ...]:
        return sleeper.get_picks(draft_id)
```

The loop never calls anything else on the client. Forecast files (S2) are
fetched once, before `run_loop`, and closed over by `recompute`.

### `recompute` must copy live draft fields onto the payload

`render` reads `payload.config.status` (refresh) and
`payload.config.pick_timer` (grey-out). The loop reads `draft.status` (poll
rate) and stops on `draft.status == "complete"`. If those diverge, the page
and the loop disagree. Copy `draft.status` and `draft.pick_timer` onto
`LeagueConfig` inside recompute.

### Errors

| Raised | Loop behaviour | CLI |
|---|---|---|
| `PlatformError` | Write last board (or an unavailable page), backoff 5s / 15s / 45s / hold, reset on success | Stay in the loop. Do not exit 2 on a transient host blip. |
| `UnsupportedLeague`, `DataRefusal`, `UserRefusal` | Write a loud unavailable page, then re-raise | Print `exc.message` to stderr, exit 2. Classes stay distinct. |

`KeyboardInterrupt` is not caught. Wrap `run_loop` if you want a clean stop,
or pass `should_stop` bound to an event.

### Poll rates (already implemented)

- `drafting` → 3s
- anything else, including `paused` and unknown → 15s
- `complete` → write once, return, no extra sleep

## Gotchas

- Recorded mid-draft `status` is `paused`. That is idle, not a fourth rate.
- `pick_timer` may be 60, 120, 0, or null. Grey-out skips 0/null.
- `gp` is shown only when `gp < 17`. Do not hide that cell; the gap between
  season points and per-game rate is the case for a discounted returning
  starter.
- The page greys the recommendation, weekly vector, and board. Banners stay
  loud on purpose.
- Age in the file is age at write time. There is no JS clock. A stuck loop
  shows a frozen age until the next successful write.
- `render` is a pure function of its four arguments. It does not touch the
  clock or the filesystem.

## Spec notes

SPEC.md §6 lists `pre_draft`, `drafting`, `complete`. Observed wire includes
`paused`. S0 already recorded that. The loop treats unknown statuses as
not-drafting.

PLAN.md D7 listed render as `(Payload, Proposal, age_seconds)`. The S7 prompt
adds `banners`. The four-argument form is the one that shipped.

## What S7 did not do

- No CLI, no default output path, no wall-clock default.
- No import of S1, S2, S4, or S5. Recompute is your closure.
- No live countdown of `pick_timer`. Data age is the clock the operator gets.
