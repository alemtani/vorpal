## Copy-paste prompt

```
Read docs/SPEC.md, docs/PLAN.md, docs/handoffs/S0.md, then docs/prompts/S9.md.

Build the evidence. You write fixtures and cases, not source.

git worktree add ../vorpal-s9 -b feat/fixtures-golden main

1. Golden set. Hand-built board states with a human-justified verdict each.
   Forbid cases: a kicker in rounds 1-3; a third TE while a dedicated starter
   slot sits empty; and more you can defend. Require cases: the superflex QB
   when two remain and eight teams need one; and more.
   Each case is a payload plus the forbid set plus the require set plus one
   sentence of human reasoning. Mark them @pytest.mark.golden.
   SPEC.md section 8 says plainly that this small human set is the main eval
   limit. Being honest about its size is part of the job — record how many cases
   there are and what they do not cover.

2. Regret fixtures. Completed public drafts, read through the same documented
   API, replayed to a user pick with the board frozen. Who survived to that
   user's next turn is a matter of record. No survival model, no judge.
   Redact hard: no manager names, no league identity. AGENTS.md forbids
   committing league data, and other people's drafts are covered by the same
   rule. If you cannot redact a draft, do not commit it.
   Their board is their ADP era, not yours. Note that on each fixture.

3. Hostile states for the sampler: an empty starter slot late, a bye stack, a
   position run in progress, a board where vols has compressed, the seat
   unknown.

Aim for breadth of situation over volume of rows.

Finish with the four handoff steps in docs/PLAN.md section 5.
```
