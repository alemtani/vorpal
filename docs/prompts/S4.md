## Copy-paste prompt

```
Read docs/SPEC.md, docs/PLAN.md, docs/handoffs/S0.md, then docs/prompts/S4.md.

Build src/vorpal/valuation/ — the numbers. Pure functions, zero network, zero IO.

git worktree add ../vorpal-s4 -b feat/valuation main

Four pieces.

1. Scoring. One function for RB/WR/TE covering rush, rec, yards, TDs, fumbles.
   Position changes replacement, not the formula, apart from rare premiums like
   bonus_rec_te. QB is pass_*. K and DST have their own keys. Longer prefix wins:
   pass_int is QB, not DST. Apply the league's scoring table to counting stats.
   Never read a fantasy-point column.

2. VOLS, two passes exactly.
   Pass 1: rank by points, fill dedicated slots (teams x slots_of_type), then
   FLEX, then SUPER_FLEX/OP, most-restrictive first.
   Pass 2: re-rank by that VOLS and fill once more. Stop. Superflex is why pass 1
   exists.
   Replacement is the first player at that position not absorbed into starting
   slots. Bench is NOT absorbed.
   vols = points - replacement[position].points.
   Market-only rows (ADP, no stats) are excluded from VOLS entirely.

3. Weekly vector, weeks 1 to 18. Rate is points/17, or points/gp when gp is
   present. Zero on the player's bye. Zero on weeks a player is known out — a
   served suspension is weeks 1..n. Do not divide by gp and then fill every
   non-bye week; that rebuilds a season the player does not play. Where gp < 17
   and the missed weeks are not knowable, do not guess which: pass gp through to
   the board row untouched and let the model read the gap.
   Fill the user's starting slots by those rates. Emit starter_points and any
   empty startable slot per week.

4. Marginal value. Recompute that vector with a candidate added; the difference
   is delta_starter_points for that candidate against THIS roster. vols is
   global and delta is not — that distinction is the point of the feature, so
   test it explicitly: the same player must produce the same vols and a
   different delta against a roster with zero RBs versus four.

Invariant test, marked @pytest.mark.invariant: a hypothetical pass 2 moves no
position's replacement rank by more than 2. A failure here is a model problem,
not a code bug — report it, do not paper over it.

TDD: failing test first. Hand-build small deterministic tables for the VOLS
tests; use tests/fixtures/ for the scoring-key coverage tests.

Finish with the four handoff steps in docs/PLAN.md section 5. S5 and S6 both
call you — docs/handoffs/S4.md must give them exact signatures.
```

## Definition of done

- Two-pass VOLS tested on a superflex table where pass 2 actually moves ranks.
- `@pytest.mark.invariant` rank-2 test present and passing on all fixtures.
- Bye week and known-out week both produce a 0 in the vector.
- `delta_starter_points` proven roster-dependent while `vols` stays constant.
