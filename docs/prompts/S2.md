## From S0

Return `StatRow`, `EcrRow`, `OverrideRow` from `vorpal.contracts`. Raise
`DataRefusal` when the file cannot be used. Field list: `docs/handoffs/S0.md`.

Gotchas:

- Join on the host player JSON `yahoo_id` (int or null), not on `Player`.
  Coerce to string vs FP `player_yahoo_id`. Many K/DEF rows have null
  yahoo ids. DST recovers on name+pos+team.
- `/players` has no bye. Live FP rows carry `player_bye_week`. Use that.
- FantasyPros: `position` is required. `ALL` is 400. ECR fetches
  `QB, RB, WR, TE, K, DST` and `OP` for superflex. Free tier returns 10
  rows (`public_api_limited`, `limit: 10`). `rank_ecr` on these lists is
  positional. Image URLs are stripped from fixtures.
- FP stat names are not host scoring keys. Map them. Unmatched nonzero
  scoring keys banner; do not silent-zero.
- Contract changes are a separate PR; do not fork types.

## Definition of done

- A test asserting no fantasy-point column can reach a `StatRow`.
- ECR-absent path produces a banner and a usable result.
- Mapping report tested at both sides of the 98% threshold.
- Stats and ECR are fetched independently (fan-out, then join).
