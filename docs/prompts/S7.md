It writes one self-contained HTML file. No server, no framework, no port, no
JS build. The page meta-refreshes. Snapshot-test the output string.

The page must show, legibly, under a pick timer:
- the recommendation, the slot it fills, the alternatives, and why
- the flags that were set

- data age, always

- status drafting: poll every 3s. Otherwise until complete: 15s.

  grey-out when the timer is 0 or null. Never present a stale board as current.
- Take the Sleeper client as an injected dependency (S1 owns it). Take a
  callable for "recompute and recommend" — do not import the model directly.
  This keeps the loop testable with a fake clock and a fake client.

TDD: failing test first.

Finish with the four handoff steps in docs/PLAN.md section 5. S8 wires you up —

## From S0

Render `(Payload, Proposal, age_seconds)` plus banners. `Payload.to_dict`
and `Proposal.to_dict` are the serialised shapes. Field list:
`docs/handoffs/S0.md`.

Gotchas:

- Draft `status` on a recorded mid-draft is `paused`, not `drafting`. Treat
  unknown statuses as not-drafting rather than inventing a fourth poll rate,
  unless the spec is amended.
- `pick_timer` may be 60, 120, or 0/null. Grey-out skips on 0/null.
- `BoardRow` has both `vols` and `delta_starter_points`. Show `gp` when
  `gp < 17`.
- Contract changes are a separate PR; do not fork types.

## Definition of done

- Snapshot test of the rendered page for a normal state and a refusal state.
- Poll cadence, backoff, degrade and grey-out all tested with a fake clock.
- Zero `time.sleep` in tests.
