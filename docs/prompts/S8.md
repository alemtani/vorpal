Finish with the four handoff steps in docs/PLAN.md section 5.

## From S7

Signatures live in `docs/handoffs/S7.md`. Short form:

```python
from vorpal.board import Frame, render, run_loop

html = render(payload, proposal, age_seconds, extra_banners)

run_loop(
    client,       # get_draft() -> Draft, get_picks() -> tuple[Pick, ...]
    recompute,    # (Draft, tuple[Pick, ...]) -> Frame
    output_path,  # Path("board.html")
    now=time.monotonic,
    sleep=time.sleep,
)
```

`Frame` is `payload`, `proposal`, `banners`. Bind S1's client to one draft
id; the loop does not take an id. Fetch S2 forecast files once, close them
over in `recompute`. Copy `draft.status` and `draft.pick_timer` onto
`payload.config` so the page and the loop agree.

`PlatformError` inside the loop backs off (5s, 15s, 45s, hold). Do not exit
2 on a transient host failure. `UnsupportedLeague`, `DataRefusal`, and
`UserRefusal` write a loud page then re-raise — print to stderr, exit 2.

`paused` polls at 15s. Grey-out skips `pick_timer` 0/null.

## Definition of done

- One command runs fixtures end to end and writes a board.
- Each refusal class exits 2 with its own distinguishable message.
- No business logic in `cli.py`.
