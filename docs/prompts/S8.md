```python
client = SleeperClient(players_cache_path=path)  # inject; default is under home

```

Keyword-only constructor. Also: `base_url`, `http`, `host`, `clock`,
`sleep`, `timeout=60.0`. Returns are generic contracts, already parsed by
`SleeperHost`. HTTP and shape failures raise `PlatformError`.

Pass `players_cache_path` so `/players` does not write under the real
home directory. Cache TTL is 24 hours.

The client waits error backoff (5s, 15s, 45s, hold) before the next HTTP
call after a failure. Do not add a second copy of that wait in the CLI
loop. Full signatures: `docs/handoffs/S1.md`.

Call `vorpal.ingest.load_forecast` once before the poll loop. Pass the
**raw** host `/players` dict (yahoo_id lives on the wire, not on

```python
from vorpal.ingest import load_forecast

stat_rows, ecr_rows, banners = load_forecast(
    season,

    override_path=override_csv_or_none,
    fp_api_key=os.environ.get("FANTASYPROS_API_KEY"),
    min_interval_s=1.1,
)
```

- `StatRow.market_only` is already set. `StatRow.adp` is already the
  chosen variant. Never read fantasy-point totals from these rows.
- FP ECR down returns empty `ecr_rows` and banner `ecr_missing`. Do not
  refuse the draft.
- Projections down with no override is `DataRefusal`. Print it, exit 2.
- Mapping under 98% on the top 300 by ADP is also `DataRefusal`; the
  message is the report.
- Recorded `players.json` is a subset. An e2e that maps it onto the
  forecast file will fail the 98% gate unless you pass a player map
  that includes those ids.
- Do not fetch FantasyPros inside the poll loop.

Full signatures: `docs/handoffs/S2.md`.

```python
resolved = resolve(
    draft,
    operator=user,
    league=league,  # required when draft.league_id is set
    scoring_league=borrowed,  # required when draft.league_id is None
    explicit_slot=cli_slot,  # optional int; partial/unset order only
    picks=picks,
    stat_columns=counting_keys,  # frozenset of counting stat columns
)
```

- Fetch projections once, collect counting keys, then resolve. Passing
  `stat_columns=None` skips the unknown-key banner. You cannot add it
  later: `LeagueConfig` is frozen.
- Print `UserRefusal` as well as `UnsupportedLeague`, `DataRefusal`, and
  `PlatformError`. Seat failures are `UserRefusal`. Exit 2.
- Surface `resolved.config.banners` before the board. Codes:
  `keepers_possible`, `slots_from_mock`, `scoring_borrowed`,
  `rec_nonstandard`, `unknown_scoring_keys`, `unstartable_scoring`.
- Drop `resolved.keeper_ids` from the player pool.
- `resolved.seat is None` ⇒ omit `next_user_pick`. Do not guess.
- Pass `resolved.config.adp_variant` and `resolved.ecr_position` (`"OP"`
  or `None`) to ingest. Do not read `draft.scoring_label`.
- Field list and gotchas: `docs/handoffs/S3.md`.
