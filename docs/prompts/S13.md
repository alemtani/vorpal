## Why this exists

S10 spent ~$13 on 73 live Opus 5 calls, most of them five identical
stability payloads. convo-agent already solved this: record once, replay
by request hash, miss loudly. Default pytest spends nothing. Only
`--record` hits the API.

Copy the shape, not the files. vorpal's seam is
`Transport.complete(payload: dict) -> dict`, not `messages.parse`.

## From convo-agent (`evals/cassette/`)

- **Replay is the default. A miss is an error.** Quiet fallback to live
  is a bill, not a red build.
- **Key the request**, not the test name. Same payload bytes → same
  cassette. Prompt or schema drift must miss.
- **A cassette is a diffable file.** Commit it. CI replays it.
- **`--record` is the only spend.** Stability's five draws are five
  samples under one key, or five keys if the payload is identical and
  you still need a distribution — decide that in the handoff; do not
  silently call five times in CI.
- **Prune unused keys.** A cassette no request can produce any more is
  litter.

See `convo-agent/evals/cassette/client.py` and
`convo-agent/tests/test_cassette.py`.
